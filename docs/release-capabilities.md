# 本版产品能力与使用范围

代码基线：`eff724d27266112bac12594ed367fed0d221c4f2`，与 [验收记录](release-acceptance.md) 一致。该提交冻结本次实现，之后的收尾提交只补充文档与证据，main 保留这一基线

本文件说明已实现的功能与输入约定，不代表全量验收通过。本轮仍有 GPU 启动失败、GLM 上游错误、Safari 流程中断和测试覆盖缺口，详见验收记录

## 产品范围

普通用户可创建和恢复草稿、上传注册视频和四路篮球视频、确认同步、提交快速或完整分析、查看视频及结构化结果、使用 AI 分析师、管理训练档案与业务 API Key

管理员使用独立后台，管理账户状态与配额、查看运行元数据、调整有上限的队列配置、执行有限重试与报告补齐、查阅持久化操作记录

管理员没有普通用户业务权限，不查看视频、报告正文、对话或训练备注，不提供代登录功能。发布、回滚、重启、数据库恢复、删除文件及密钥修改仍在服务器端完成

## 输入约定

- 注册方式为逐人出镜或多人并排，提交前明确 1–6 名参与者
- 注册人数与有效登记样本必须匹配，登记不足不会静默截断后继续生成个人结果
- 使用注册视频以及 cam_01、cam_02、cam_03、cam_04 四路视频，草稿允许先上传再命名
- 同步以机位 3 为参考，公共时间等于本地时间减去机位偏移
- 四路选择同一真实事件或提交已知偏移，数值校验不能证明选中的事件真实对应
- 首版支持恒定帧率、没有中途剪接或变速、具有共同可见事件和重叠时段的视频，仅校正常量偏移，不补偿时钟漂移
- 更换动作视频使原同步确认失效，更换注册视频不影响同步；取消同步弹窗不保存本次调整
- 登记失败时可返回输入页面修正，保留原上传文件；历史已提交任务不因新增必填参数被追溯阻断

动作、命中和姿态结果仍受输入质量及现有科研模型能力约束。未确定投篮不作为未命中，缺少可信身份、标定或关键点时不输出虚构个人或三维指标。具体样例表现以验收记录为准，不据少量样例推导普遍准确率

## AI 分析与训练档案

视频成功后进入独立 AI 队列，按任务语言准备全场与各匿名球员的教练、球友两种语气报告。已完成报告可直接切换，刷新只重新生成当前版本，AI 失败不改变视频分析的成功状态

训练档案保存用户确认的身份关联、目标、备注和简洁训练记录，不跨任务自动认定相同编号是同一个人。绑定需要明确确认；满足条件后可主动追加历史对比，本场原报告不被改写

报告、追问与预置报告共用应用并发控制，默认 8。应用上限不能提高 GLM 供应商账户额度，限流、等待、超时及格式或引用校验失败仍可能发生。未配置服务端 Key 时原视频与数据功能可用，分析师显示未启用

## 网页与 API

分步 `/api/v1/tasks` 与一次上传 `/api/v1/analyses/upload` 共用注册、同步、配额及调度规则。API 可直接提交同步数据，不要求打开网页弹窗

旧路由与既有字段保留，但新提交必须补齐人数及同步数据，一次上传还需显式提供注册方式与分析语言。缺少参数为 422，同步版本冲突为 409。完整请求、预览、返回输入及错误说明见 [输入与 API 指南](input-and-api-guide.md) 和站内 API 文档

## 账户升级与运维边界

已有账户不根据名称自动晋升管理员，账户迁移使用显式服务器命令。迁移旧 admin 的业务数据至普通账户、撤销旧密钥和会话仅在隔离数据中验证，本轮不执行生产迁移

暂停领取或停用账户不终止已运行视频任务；新请求受到会话版本、账户状态与角色校验约束。管理修复仍受单日、单作业及批量限制，具体值读取实际配置

当前访问方式继续采用 SSH 隧道，发布继续采用 SCP。交付恢复脚本与隔离演练记录，不代表已验证生产恢复能力，也不建立定时备份任务

| 普通接口 | 本机隔离环境下，1、5、10、20 用户的任务列表读取共 720 次，全部成功；未验证持续在线容量或同时上传、分析的负载 |
