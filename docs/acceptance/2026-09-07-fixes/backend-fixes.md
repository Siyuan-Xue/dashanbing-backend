# 后端缺陷与回归说明

## 产品改动

1. 科研入口先设置当前任务和模型路径，再导入身份模块，避免 `src.config` 提前缓存默认目录。独立子进程测试先复现错误目录，修复后确认模型、数据和隐私图库指向当前输入
2. 预置 GLM 请求直接发送已有的 64 位作业标识，移除导致请求超过供应商长度上限的前缀，去重标识、账本和模型参数保持不变
3. AI 领取不在异步事件循环中等待 SQLite 写锁，使失败请求的依赖清理能够释放事务。采用真实五秒 busy 边界和事件顺序判断，未设置“必须小于若干毫秒”的性能断言
4. 已取消的领取等待线程完成，处理持久化任务中断和释放；领取或清理异常不能覆盖取消信号，重复取消不能遗留 lease 或内核锁
5. 视频领取遇到忙锁后继续原循环，避免一次异常永久停止后台领取；停止期间等待领取结束并释放视频互斥锁，尚未开始执行的任务保留排队状态

视频执行数量、AI 并发、供应商限流退避、实际调用次数、自动和主动生成配额、生产忙锁等待及输入校验均未放宽。异常处理是功能恢复，不以降低测试耗时为目标

## 原 25 项测试失败

原始逐项编号和失败见 [首轮归因](../2026-09-07/failure-triage.md)。修复测试使用批准的新契约，而不是改变业务以迎合旧断言

- 限额从持久化账户配置读取，单独验证个人限额与默认值不同
- 实际 AI 调用计数在供应商调用前产生，领取后即撤销不会虚增调用；配额账本、请求身份与撤销后限制仍保留断言
- 撤销竞态夹具具备有效待执行报告和真实可比历史，确保确实进入供应商等待与晚到写回路径；8 个组合继续验证另一账户、无关上下文、账本和租约不被修改
- 科研回归提供有效登记图库，保留人数、姿态可靠性、源任务目录和结果不可覆盖检查
- 预置 CLI 测试运行真实入口和持久化服务，仅替换供应商传输，验证语言、球员、语气集合、已验证文件复用、去重、用量和租约释放
- 初始化账户密码沿用数据库而不被环境变量覆盖；返回字段、注册/同步清单、任务独立偏移按新增协议明确断言

新增回归为 `tests/test_product_runtime_bootstrap.py`、`tests/test_analyst_claim_liveness.py`、`tests/test_video_claim_liveness.py`。SQLite 取消和忙锁测试使用隔离数据库及真实内核锁，不调用真实 GLM 或模型；独立评审的内存探针另行标记，不当作端到端 GPU 证据
